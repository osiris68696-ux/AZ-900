# AZ-900 互動考古題

這是一個可直接部署到 GitHub Pages 的靜態網站。

## 上傳到 GitHub Pages

1. 建立 GitHub repository，例如 `AZ-900-interactive-practice`。
2. 將以下檔案與資料夾上傳到 repository 根目錄：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `data/questions.js`
   - `assets/gengar.gif`
   - `assets/pikachu.gif`
   - `assets/pikachu-transparent.gif`
3. 到 repository 的 `Settings` -> `Pages`。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/root`。
6. 儲存後等待 GitHub 產生網址。
